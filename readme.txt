Family trees for WordPress: GEDCOM import and export, a groups explorer, an interactive tree and person pages.

== Description ==

GenoRoots turns GEDCOM files into an explorable family archive.

* Groups explorer: every family group as a bubble, overlaps drawn to scale.
* Interactive, focus-centred family tree that loads more as you click.
* A page for every person, with portrait, dates, places, notes and relatives.
* GEDCOM 5.5 import and export, safe to re-run.
* Collections for several unrelated family networks on one site.
* Conversion from the Genealogical Tree plugin, keeping old numbers and URLs.
* WP-CLI commands with dry runs and rehearsals.
* English and Greek interface.

Requires the free Advanced Custom Fields plugin.

Full documentation: https://github.com/nikolakakis/geotour-genoroots

== Installation ==

1. Install and activate Advanced Custom Fields.
2. Upload the plugin zip under Plugins → Add New → Upload Plugin, and activate it.
3. Import a GEDCOM file under GenoRoots → Import GEDCOM.
4. Visit /family-tree/ on your site, or put [genoroots_app] on any page.
